# datathon_26_xin_chao

## Repository layout

```text
datathon_26_xin_chao/
├── data/
│   ├── open/
│   │   ├── open_labels.xlsx
│   │   └── videos/
│   └── open.zip
├── docs/
│   └── ForteBank case description.pdf
├── README.md
└── .gitignore
```

- `data/open/` contains the extracted dataset, with 42 videos and their label workbook.
- `data/open.zip` is the original dataset archive, kept locally and excluded from the commit.
- `docs/ForteBank case description.pdf` contains the competition case description.

Dataset filenames are preserved as provided. Video names use both Latin `X` and Cyrillic `Х`.
